### devboard
this is a silly devboard with a rp2040 and battery controller, it should work with most single cell lipo batteries
<img width="635" height="785" alt="image" src="https://github.com/user-attachments/assets/c86d8a69-558f-49df-bb30-a14af1582a0f" />

there's 16MB of flash memory by default, you can just change it in the bom, the prod files are for jlcpcb pcb assembly
it *should* work as a raspberry pi pico because most of the components are the same
there's a 3.3v in and gnd connector next to the battery connector
you can just use it like any other microcontroller
basically, this is just a fun, simple microcontroller
